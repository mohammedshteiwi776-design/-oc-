# 1. عنوان المشروع (Project Title)
### **Binary Search Algorithm with Execution Trace**
**خوارزمية البحث الثنائي مع تتبع خطوات التنفيذ**

---

# 2. وصف المشروع (Description)
هذا المشروع عبارة عن أداة تعليمية وتطبيقية مكتوبة بلغة **C++**. يقوم البرنامج بتنفيذ خوارزمية **البحث الثنائي (Binary Search)**، وهي واحدة من أسرع طرق البحث في المصفوفات المرتبة.

ما يميز هذا الكود هو خاصية الـ **Trace Table**؛ حيث لا يكتفي البرنامج بإيجاد العنصر فحسب، بل يقوم بطباعة جدول يوضح بالتفصيل كيف تتغير قيم المؤشرات (`low`, `high`, `mid`) في كل دورة (Iteration)، مما يجعله مثالياً للطلاب والمبرمجين الراغبين في فهم كواليس عمل الخوارزمية.

---

# 3. الميزات التقنية (Key Features)
* **خوارزمية فعالة:** تعقيد الوقت هو $O(\log n)$.
* **تتبع حي (Live Tracing):** عرض جدول يوضح عملية تقسيم المصفوفة خطوة بخطوة.
* **تنسيق احترافي:** استخدام مكتبة `<iomanip>` لضمان ظهور البيانات بشكل منظم في الشاشة السوداء (Console).
* **معالجة الأخطاء:** حساب الـ `mid` بطريقة تمنع الـ Overflow (تجاوز سعة الذاكرة).

# 5. كيفية الاستخدام (How to Use)
1.  قم بتنزيل الملف أو عمل `clone` للمستودع.
2.  تأكد من أن المصفوفة المعرفة داخل الدالة `main` مرتبة تصاعدياً.
3.  قم بتغيير قيمة `target` إلى الرقم الذي تود البحث عنه.
4.  قم بتشغيل الكود وراقب الجدول الناتج.
